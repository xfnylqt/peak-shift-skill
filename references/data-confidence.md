# 数据可信度与使用限制

## 一、三级可信度

本 Skill 的电价数据对每一条标注 `confidence`，**未核实的数据不会被伪装成权威数据**。

| 级别 | 含义 | 使用方式 |
|---|---|---|
| `official` | 政府 / 发改委 / 电网公司**官网原文** | 可直接使用 |
| `official-media` | 官方媒体转载的**官方文件**（如「上海发布」） | 可使用，建议向用户提示可核对原始文件 |
| `unverified` | 自媒体汇编，**未找到官方原文** | ⚠️ **必须标注「尚未核实」，不得作为决策依据** |

## 二、首次引入的 `residential_tou_available`

这是本数据集的关键字段：

| 取值 | 含义 |
|---|---|
| `true` | 该地区居民生活用电执行峰谷分时电价 |
| `false` | **不执行**，且必须提供 `no_tou_reason` 字段说明原因 |

配套字段：

| 字段 | 说明 |
|---|---|
| `no_tou_reason` | 官方给出的不执行原因（原文或摘要） |
| `exception` | 例外情形（如电采暖、居民充电桩另有峰谷价格） |
| `flat_price` | 该地区居民统一电价（不执行分时时的实际电价） |

> **设计意图**：「没有峰谷」也是**有效的信息**，必须被记录。用户被「某某攻略说能省钱」误导，往往是因为没人告诉他本地根本不执行。

## 三、`null` 的含义

价格字段为 `null` **不等于 0**，而是「**时段已确认，但电价值尚未从官方原文核实**」。

当前存在 `null` 的地区：

| 地区 | 情况 |
|---|---|
| 四川 | 时段来自省发改委文件，电价数值未核实 |
| 广西 | 居民充电桩峰谷为浮动值（±0.10 元），平段基准待确认 |
| 内蒙古（蒙东） | 数据源为 2023 年听证方案，实施状态待核实 |
| 湖北 | 整条记录为 `unverified` |

**遇到 `null` 时**：明确告知用户该地区数据不完整，**不要用邻近省份数据替代**。

## 四、时效性

电价政策以**年度**为周期调整，且会因电力供需变化而临时调整（如迎峰度夏期间的工商业电价）。

**必须向用户提示**：数据采集日期见各省文件的 `accessed_date`，实际以当地供电部门公布的最新信息为准。

## 五、使用限制清单

| 限制 | 说明 |
|---|---|
| ❌ 不编造 | 数据缺失时明确说明，不按比例推算后当作官方值 |
| ❌ 不跨省套用 | 不执行峰谷的地区，不得用邻省数据顶上 |
| ❌ 不承诺金额 | 所有节省均为估算，依赖用户提供的功率与作息 |
| ❌ 不覆盖工商业 | 本数据仅针对居民生活用电及其他明确标注的用户类型 |
| ⚠️ 标注来源 | 输出必须附机构名与生效日期 |

## 六、如何贡献数据

见源仓库 `cn-tou-tariff` 的 `CONTRIBUTING.md`。核心原则：

> **宁可标注「未核实」，也不要填入不确定的数值。**
>
> 用户会依据这些数据做真实的用电决策，**错误的数据比没有数据更糟**。
